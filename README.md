# Bunny Walk 🐇

A tiny white pixel rabbit that wanders along the bottom of Firefox pages. It idles between short walks in random directions. Click it to pause or resume; use the toolbar popup to hide or show it.

## Install in Firefox

1. Open `about:debugging#/runtime/this-firefox`.
2. Choose **Load Temporary Add-on…** and select this folder's `manifest.json`.
3. Open a regular website to see the bunny. The extension asks for access to all websites so it can appear on them.

Temporary add-ons are removed when Firefox restarts.
